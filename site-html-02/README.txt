ПРАКТИЧЕСКАЯ РАБОТА №2 — HTML5

1. Распакуйте архив целиком. Откройте site-html-02/index.html двойным щелчком.
2. Для редактирования откройте папку site-html-02 в VS Code.
3. Сайт работает без установки зависимостей и без интернета (кроме внешних ссылок).
4. В отчёте заполните группу. Имя автора указано: Влад Новиков.
5. Проверьте index.html на https://validator.w3.org/ через загрузку файла.
6. Сделайте скриншоты шапки, содержимого и подвала (Win + Shift + S).
7. Для публикации загрузите папку сайта в Netlify или файлы в GitHub Pages.
   Инструкция и поле для адреса находятся в PDF-отчёте.
8. Сдайте исходники, отчёт, скриншоты и ссылку на публикацию.

Проверены локальные ссылки, изображение, обязательные теги, alt и заголовок h1.
Просмотр в браузере, внешняя валидация W3C и публикация не выполнены.
Данные клуба вымышлены и явно отмечены как учебные.
